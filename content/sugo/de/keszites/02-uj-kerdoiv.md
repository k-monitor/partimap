# Neue Umfrage erstellen und bestehende verwalten

Eine neue Umfrage erstellen Sie auf der Seite **Umfragen**.

### Schritte:

1. Geben Sie den Namen der Umfrage ein
2. Klicken Sie auf die Schaltfläche **Hinzufügen**

Damit wird die neue Umfrage angelegt.

<figure>
	<img src="/help/sugo/keszites-new-survey.jpg" alt="Umfrage erstellen" />
	<figcaption>Ablauf beim Erstellen einer Umfrage</figcaption>
</figure>

In der Umfrageliste sehen Sie:

- das Erstellungsdatum
- die Anzahl der Aufrufe
- die Anzahl der Antworten
- die Möglichkeit, den Bericht herunterzuladen

Mit der Schaltfläche **Bericht generieren** exportieren Sie die Ergebnisse im Format `.xlsx`.

Im ⋮-Menü stehen weitere Optionen zur Verfügung:

- Umfrage löschen
- Duplizieren
- Definition herunterladen
- An anderen Benutzer übertragen

> ⚠️ **Wichtig:** Die Funktion „Duplizieren“ übernimmt keine bisherigen Antworten und eignet sich daher ideal, um Testversionen live zu schalten.
