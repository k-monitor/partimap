# Kartenelemente durchsuchen und bewerten

Auf einigen Arbeitsblättern können Sie die auf der Karte eingezeichneten Elemente durchsuchen.

## Bedienung der Karte

	<img src="/help/sugo/kitoltoknek-map-controls.jpg" alt="Interaktionen der Teilnehmenden auf Karten-Arbeitsblättern" />
	<figcaption>Interaktionen der Teilnehmenden auf Karten-Arbeitsblättern.</figcaption>
</figure>

### 1. Position erfassen

Mit einem Klick auf das Standortsymbol in der rechten Ecke der Karte können Sie Ihre aktuelle Position erfassen.
Dazu müssen Sie im Browser die Freigabe Ihres aktuellen Standorts erlauben.

### 2. Zwischen Basiskarten wechseln

Mit einem Klick auf das **Kartensymbol** in der rechten unteren Ecke der Karte wechseln Sie zwischen den Basiskarten:

- Schwarz-Weiß,
- Satellitenbild,
- topografische Ansicht,
- oder Straßenansicht.

### 3.-4. Ansicht vergrößern und verkleinern

Zoomen können Sie:

- mit dem Mausrad,
- mit den Schaltflächen + / –,
- oder auf dem Smartphone mit zwei Fingern.

> 💡 **Tipp:** Für genaue Markierungen empfiehlt es sich, in die Karte hineinzuzoomen.

## Kartenelemente öffnen

Zu den Elementen können eine Beschreibung und weitere Informationen gehören.

Sie können diese öffnen:

- direkt auf der Karte, indem Sie auf das Element klicken,
- oder über die Liste in der Seitenleiste.

<figure>
	<img src="/help/sugo/kitoltoknek-open-features.jpg" alt="Kartenelemente öffnen" />
	<figcaption>Möglichkeiten zum Öffnen von Kartenelementen auf Karten-Arbeitsblättern</figcaption>
</figure>

Die Elemente können Kategorien zugeordnet sein. Diese werden unter dem Feld „Suche…“ angezeigt und können zum Filtern der Kartenelemente verwendet werden.

## Kartenelemente bewerten

Bei der Erstellung des Fragebogens kann auch eine Bewertung der Kartenelemente angefordert werden.

Die Bewertung kann folgende Form haben:

### Sternebewertung

<figure>
	<img src="/help/sugo/kitoltoknek-rating-stars.png" alt="Sternebewertung" />
	<figcaption>Bewertungsmöglichkeiten auf Karten-Arbeitsblättern: Sterne</figcaption>
</figure>

Sie können die Elemente mit Sternen auf einer Skala von höchstens fünf Sternen bewerten.

### Bewertung „Daumen hoch/runter“

<figure>
	<img src="/help/sugo/kitoltoknek-rating-like.png" alt="Bewertung mit Daumen hoch / Daumen runter" />
	<figcaption>Bewertungsmöglichkeiten auf Karten-Arbeitsblättern: Daumen-hoch/runter-Schaltflächen</figcaption>
</figure>

Sie können den Elementen:

- eine positive 👍
- oder eine negative 👎 Rückmeldung geben.

In bestimmten Fällen bittet das System auch um eine kurze schriftliche Begründung oder einen Kommentar.

## Nutzung auf Smartphone und Tablet

Auf Smartphones und Tablets werden die Karte und die Seitenleiste kleiner angezeigt.

Die Seitenleiste lässt sich:

- ausblenden,
- und anschließend mit den entsprechenden Schaltflächen wieder öffnen.

Wenn Sie in der Seitenleiste ein Element auswählen, navigiert das System über die Schaltfläche **Auf Karte zeigen** automatisch an die richtige Stelle.

Wenn Sie auf der Karte auf markierte Elemente klicken, erscheinen nach einer kurzen Verzögerung:

- die Beschreibung,
- sowie die Bewertungsmöglichkeit.

Auf dem Smartphone gelangen Sie nur über die Schaltfläche am unteren Rand der geöffneten Seitenleiste zur nächsten Seite.
