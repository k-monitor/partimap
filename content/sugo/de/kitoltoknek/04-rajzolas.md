# Auf der Karte zeichnen

In manchen Teilen des Fragebogens können auch Sie selbst Markierungen auf der Karte setzen.

Versuchen Sie stets, die Markierungen so genau wie möglich zu platzieren.
Zoomen Sie bei Bedarf in den gewünschten Bereich hinein, oder erfassen Sie Ihre aktuelle Position mit einem Klick auf das Standortsymbol in der rechten Ecke der Karte.

Dazu müssen Sie im Browser die Freigabe Ihres aktuellen Standorts erlauben.

Nach dem Zeichnen können:

- Textfragen,
- eine Begründung,
- oder weitere Antwortfelder erscheinen.

## Punkt setzen

Wenn Sie einen bestimmten Ort markieren möchten:

1. Klicken Sie auf das 📍 Stecknadelsymbol.
2. Klicken Sie auf die gewünschte Stelle auf der Karte.
3. Schreiben Sie bei Bedarf im sich öffnenden Fenster einen Kommentar oder eine Begründung.

Die Markierung können Sie:

- mit der Schaltfläche **Speichern** festhalten,
- oder mit der Schaltfläche **Markierung löschen** entfernen.

Danach können Sie weitere Punkte hinzufügen.

## Linie zeichnen

Wenn Sie eine Route oder einen Abschnitt markieren sollen:

1. Klicken Sie auf das Liniensymbol.
2. Setzen Sie mit einem Klick den Startpunkt.
3. Legen Sie mit weiteren Klicks die Zwischenpunkte fest.
4. Doppelklicken Sie zum Abschließen auf den Endpunkt.

<figure>
	<img src="/help/sugo/kitoltoknek-draw-line.png" alt="Linie zeichnen" />
	<figcaption>Eine Linie auf einem interaktiven Karten-Arbeitsblatt zeichnen</figcaption>
</figure>

Nach dem Abschließen der Zeichnung können Sie dem Element auch einen Kommentar hinzufügen.

Die Linie können Sie:

- speichern,
- bearbeiten,
- oder löschen.

## Fläche markieren

Wenn Sie eine ganze Fläche markieren möchten:

1. Klicken Sie auf das Symbol zum Markieren einer Fläche.
2. Legen Sie die Randpunkte mit Klicks fest.
3. Schließen Sie die Fläche ab, indem Sie auf den Startpunkt klicken.

<figure>
	<img src="/help/sugo/kitoltoknek-draw-polygon.png" alt="Fläche markieren" />
	<figcaption>Eine Fläche auf einem interaktiven Karten-Arbeitsblatt markieren</figcaption>
</figure>

Nach dem Abschließen können Sie:

- eine Begründung angeben,
- einen Kommentar schreiben,
- und das Element anschließend speichern oder löschen.
