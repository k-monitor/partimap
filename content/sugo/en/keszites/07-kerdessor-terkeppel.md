# Questions and map sheet

The Questions and map sheet is used to create map-based surveys in which respondents view a prepared map and then answer questions about what they see. On this sheet, respondents cannot draw on the map; they can only view and rate the elements shown on it.

With this sheet you can:

- present existing or planned developments,
- collect opinions and feedback,
- have map elements rated,
- display statistics and aggregated results.

## Main settings

When editing the sheet, you can set:

**Sheet title** – appears in the header of the public survey, so give it a title you don't mind your respondents seeing.

**Sheet description** – informational text shown at the start of the survey, which can be formatted. In the sheet description you can:

- Insert an image
- Add a link to text
- Insert a video
- Format text: bold and italic
- Insert headings
- Create bulleted lists
- Align text to the center, right or left.

**Survey** – this is where you add and edit the questions of the survey.

**Display results to visitors after submitting the sheet** – after answering, respondents can see aggregated results for each question in chart form.

**Share page on social media** – turns on or off the buttons that help share the survey.

**Default base map** – for example a road network, satellite, cycling or topographic map.

**Markers on the map** – points, lines and areas, to which you can assign a name, description, color, size and category.

> ⚠️ **Important:** Changes are only stored when you click the **Save** button. Saved changes appear in the public survey immediately.
