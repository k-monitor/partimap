# Registration

After registering, anyone can use the full PARTIMAP application free of charge.
Using our [GitHub page](https://github.com/k-monitor/partimap), you can even deploy the survey on your own server.

The features of the PARTIMAP application really are free, but there are some services we provide for a fee; [you can find out more here](/en/pricing).

The system is currently available in the following languages:

- Hungarian
- English
- German
- Lithuanian
- Spanish
- Romanian

You can switch between languages with the 🌐 button in the top right corner.

> ⚠️ **Important:** If you would like to use PARTIMAP in another language and would help with the translation, write to us: hello@PARTIMAP.eu

After logging in, two main areas are available in the admin interface:

- **Surveys** → creating and editing surveys
- **Maps** → managing and storing map elements
