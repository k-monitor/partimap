# Report and results

You can download the submissions of a survey in .xlsx format from the [Surveys list view](/en/admin/projects) page. The report contains the results in the format described earlier. The map elements can also be linked to the answers given to the survey questions via ID numbers, for example to the demographic data of the respondents. Once the data are linked, the spatial markings can also be analyzed in more depth and filtered by particular groups of respondents. The report also includes the type of device used by the respondent (pc/mobile) and the respondent's IP address.

The site does not allow mass automated submissions, but it is possible to submit several responses manually from the same IP address. These can be filtered out of the report by IP address.
