# Text sheet

The Text sheet is used to display informational content. You can use it to present the purpose of the survey, the organization or institution running it, the background of the decision at hand, and how the participation process works.

When you create a new survey, the system automatically creates a sheet of this type, so respondents can learn the necessary information right at the start of the survey.

On the Text sheet, you can edit the following:

**Sheet title** – appears in the header of the public survey.

**Sheet description** – the main body text, which can be formatted. In the sheet description you can

- Insert an image
- Add a link to text
- Insert a video
- Format text: bold and italic
- Insert headings
- Create bulleted lists
- Align text to the center, right or left.

**Background image** – sets the image shown behind the sheet.

**Wide sheet** – with this option, the survey creator can give respondents a wider panel for filling in the survey.

**Share page on social media** – turns on or off the buttons that help share the survey on social media.

> ⚠️ **Important:** Changes are only stored when you click the **Save** button. Saved changes appear in the public survey immediately.
