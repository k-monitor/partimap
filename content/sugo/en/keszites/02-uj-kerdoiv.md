# Creating a new survey and managing existing ones

You can create a new survey on the **Surveys** page.

### Steps:

1. Enter a title for the survey
2. Click the **Add** button

This creates the new survey.

<figure>
	<img src="/help/sugo/keszites-new-survey.jpg" alt="Creating a survey" />
	<figcaption>How to create a survey</figcaption>
</figure>

The survey list shows:

- the creation date
- the number of views
- the number of submissions
- the option to download the report

With the **Generate report** button, you can export the results in `.xlsx` format.

More options are available in the ⋮ menu:

- delete the survey
- duplicate
- download definition
- transfer to another user

> ⚠️ **Important:** The “Duplicate” function does not carry over previous responses, which makes it ideal for turning a test version into the live survey.
