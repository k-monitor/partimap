# Map types

OSM (OpenStreetMap)

The most general map view.

- streets, roads and buildings are clearly visible,
- it contains detailed information about towns and cities,
- recommended for urban and general surveys.

If you're not sure which base map to choose, this is the safest choice.

#### CycleOSM

A map optimized for cycling.

- highlights cycle paths,
- shows cycling infrastructure and routes,
- ideal for surveys on transport and cycling.

Especially useful when evaluating or planning cycling networks.

#### Toner

A minimalist, black-and-white map.

- provides strong contrast,
- shows less background information,
- your own map elements stand out more.

Recommended when the focus is on the drawn points, lines or areas.

#### Terrain

A relief map.

- shows the terrain,
- highlights mountains, valleys and differences in elevation,
- useful for projects on nature, tourism or land use.

Especially suitable for presenting outlying and natural areas.

#### ESRI-WI (Esri World Imagery)

A map based on satellite and aerial imagery.

- shows the actual surface,
- buildings, roads, vegetation and other features are visible,
- excellent for presenting developments or land use.

Use it when it's important that respondents see the actual surroundings.

## Importing map elements

Elements can be loaded onto the map in several ways, using the **Import markers** window:

- **from an existing map stored in the Maps menu** – by selecting the map in the *Import from a map* section;
- **from other sheets** – in the *Import from a sheet* section, by selecting the survey and the sheet;
- **from elements submitted on a Map tasks sheet** – using the *Import submitted markers* function;
- **from fixed elements saved on other sheets** – with the *Import fixed markers* option;
- **from an external source, using a KML file**.

The import window also shows the number of elements that can be imported from each source (e.g. “Import 0 marker(s)”, “Import 0 submitted marker(s)”, “Import 0 fixed marker(s)”).

> 💡 **Tip:** You can also restrict the visible area of the map and the zoom range available to respondents.

## Rating map elements

You can turn on the **Rate static features** function, which lets respondents give their opinion on the map elements.

Two rating types are available:

- **Star-rating** ⭐ (1–10 stars)
- **Upvote/downvote rating** 👍👎

Optionally, you can also ask for a written explanation of the ratings:

- as a free-text answer,
- with positive and negative points given separately.

### Displaying results

The system can display:

- the average rating of each element,
- the number of ratings,
- aggregated statistics of the answers to the sheet's questions.

> 💡 **Tip:** You can also set up a view where visitors only see the results and cannot submit new responses.

### Creating map elements

You can also draw elements directly in the editor:

- **Point** – placed with a single click.
- **Line** – drawn by connecting several points.
- **Area (polygon)** – created as a closed shape.

The appearance of the drawn elements can be customized in detail:

**Name** – the name of the element.

**Color** – choosing the color of the element.

**Size** – setting the size of the element.

**Extra stroke** – for example, adding a gray outline to the element.

**Opacity** – controls how transparent the element is (0–100%). For areas, the fill color can also be made fainter.

**Label on map** – the text of the label shown next to the element.

**Category name** – assigning the element to a category.

**Description** – a detailed text description, with formatting options:

- headings (H1, H2),
- paragraph,
- bulleted list,
- alignment,
- bold and italic text,
- inserting a link,
- inserting images and videos,
- undo and redo.

**Hide from the list of features** – the element can be hidden from the list view.

**Delete feature** – deletes the element.

#### Categories and auxiliary elements

Map elements can be sorted into categories, which makes it easier for respondents to filter them.

> 💡 **Tip:** An element can also be hidden from the interactive list. It then remains visible on the map but cannot be clicked. This is useful, for example, for displaying city boundaries or other elements that help with orientation.

#### Mobile use

On mobile phones and tablets, you can switch between the map and the sidebar with the hide and show buttons. The drawing tools are available in the map view.

> ⚠️ **Important**: By default, the map shown to respondents always starts from a view that fits all the drawn elements.
