# Questions sheet

The Questions sheet is used to create traditional questionnaire surveys. With it, you can add different types of questions to the survey and control how they are displayed and answered, as well as how the results are displayed.

On the Questions sheet, you can edit the following:

**Sheet title** – appears in the header of the public survey, so give it a title you don't mind your respondents seeing.

**Sheet description** – informational text shown at the start of the survey, which can be formatted. In the sheet description you can:

- Insert an image
- Add a link to text
- Insert a video
- Format text: bold and italic
- Insert headings
- Create bulleted lists
- Align text to the center, right or left.

**Survey** – this is where you add and edit the questions of the survey.

**Display results to visitors after submitting the sheet** – after answering, respondents can see aggregated results for each question in chart form.

**Display only the results** – closes the survey, so no new responses can be submitted and only the results can be viewed.

**Background image** – sets the image shown behind the sheet.

**Wide sheet** – with this option, the survey creator can give respondents a wider panel for filling in the survey.

**Share page on social media** – turns on or off the buttons that help share the survey.

> ⚠️ **Important:** Changes are only stored when you click the **Save** button. Saved changes appear in the public survey immediately.

## Managing questions

In the Survey block, questions can be:

- Deleted with the trash can icon
- Moved to another sheet with the move icon
- Rearranged by drag and drop, using the question's handle
- You can set the Required question option for them, so the respondent can only move on after answering.
- By ticking the Add responses to map markings for analysis purposes option, the answer is included in the map exports (.kml), so the map data can later be filtered and analyzed.

## Available question types

### Text box (short)

The respondent can freely enter a text answer. The report contains the text entered.

Ticking the Multiline text checkbox turns the text box into a two-line box.

> 💡 **Tip:** If you want to collect several short text answers (for example, three keywords), use several Text box fields one after the other.

### Numeric text box

The respondent can type in a number. You can also set a minimum and a maximum value.

### Numeric slider

The respondent can set a numeric value with a slider. Besides the minimum and maximum values, the two ends of the scale can also be given text labels.

### Checkboxes

The respondent can select several answer options.

You can set:

- Any number of answer options
- The maximum number of answers that can be selected
- An “Other...” option where respondents can enter their own text answer
- Options can also be shuffled

### Multiple choice

The respondent can choose one of the given answer options.

You can set:

- Any number of answer options
- An “Other...” option where respondents can enter their own text answer
- Options can also be shuffled

### Drop-down (one answer)

The respondent chooses one option from a drop-down list.

You can also add an “Other...” answer.

### Star-rating (1-5)

The respondent can rate the question or statement with 1–5 stars.

### Multiple choice grid

A question type made up of several rows and columns.

- The rows are the items to be rated.
- The columns are the answer options.
- One answer can be selected for each row.
- It can be made mandatory to give at least one answer for each row.

### Checkbox grid

An extended version of the Multiple choice grid.

- The rows are the items to be rated.
- The columns are the answer options.
- Several answers can be selected for a row.
- It can be made mandatory to give at least one answer for each row.

### Allocate units (weighting)

The respondent has to distribute a predefined number of points or units among the answer options.

This question type is especially suitable for:

- assessing priorities,
- establishing an order of importance,
- weighting topics or problems.

### Ordering

The respondent can put the given items in order by importance, preference or another criterion. The order of the items can usually be changed by drag and drop.

This question type is especially suitable for:

- setting priorities,
- ranking favorite options,
- determining the order of importance of development needs or problems.

The report contains the order given by the respondent.

## Conditional questions

The display of a question can be made dependent on the answer to a previous question. This applies to every question type.

You can set the condition in the question's editing window, with the “Show only if...” setting.

With conditional questions:

- the survey can be made shorter,
- respondents only see relevant questions,
- the experience of filling in the survey can be improved.

**Example:** Questions about car use are only shown to those who indicated earlier that they have a car.

> ⚠️ **Important:** Once a conditional link has been created, the order of the questions and of the sheets involved can only be changed to a limited extent, and the answer options of the questions that set the condition cannot be changed either.
