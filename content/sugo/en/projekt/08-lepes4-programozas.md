# Step 4: Programming the questionnaire

Once the structure of the questionnaire is ready and the questions have been finalized, you can move on to programming the questionnaire in PARTIMAP.

The technical settings are described in detail in the PARTIMAP help center, but a few practical considerations are worth keeping in mind from the very beginning.

## Use the right map

For map questions, always set in advance the area the question refers to. That way respondents immediately see the right town or neighborhood and don't have to navigate there manually.

For example, for a questionnaire about Veresegyház, set up the map so that it shows Veresegyház by default, not Budapest.

## Keep it simple and easy to use

Most respondents spend only a few minutes on the questionnaire, so it's important for the interface to be clear.

It's worth:

- using short questions;
- avoiding overly long explanations;
- grouping the questions logically;
- giving clear instructions for every question.

## Write in a direct tone

Experience shows that addressing respondents informally is more personal and direct, so it's worth doing so in most questionnaires aimed at residents.

## Use question logic

Not every question needs to be shown to every respondent.

If a question is relevant only to a particular group, use PARTIMAP's conditional display (logic) options.

**For example:**

- only those raising young children get questions about playgrounds;
- only those who travel by car see the questions about parking;
- questions about cycle paths are shown only to cyclists.

This makes the questionnaire shorter, and respondents encounter more relevant questions.

## Test the questionnaire

Before making the questionnaire public, always ask a few colleagues or friends to fill it in.

During testing, check whether:

- every question is understandable;
- the skips and conditions work properly;
- the map is displayed correctly;
- the questionnaire is easy to use on a mobile phone too;
- it really can be completed in the time you planned.

A short test can prevent many problems later on.
