# Planning the questionnaire

Before you create the first question, it is worth thinking through the purpose of the questionnaire.

Answer the following questions:

- What do you want to find out?
- What decision do you want the results to support?
- Who will the respondents be?
- How long a questionnaire are they willing to complete?

If there are no clear answers to these, the questionnaire can easily become too long or inconsistent.

A useful method is to write next to each question:

**"What analysis will I need this answer for?"**

If you can't answer this, you probably don't need that question.

## Questionnaire length

There is no general rule for how many questions a questionnaire should contain. The goal is to include every question needed to achieve the research objectives, without placing an unnecessary burden on respondents.

Before adding each new question, consider whether it is really needed for the analysis. Unnecessary questions increase completion time and can lower the completion rate. If the questionnaire is aimed at different target groups, it is a good idea to use branching (conditional questions), so that respondents only see the questions relevant to them.
