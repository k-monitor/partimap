# Question order

The order of the questions can influence the answers.

General rules:

- simple questions should come first;
- general questions should precede more detailed ones;
- open questions should ideally precede closed questions on the same topic;
- sensitive questions should go at the end;
- the questions should tell a logical story.

## Using branching

Questionnaires often use branching (skip logic), which lets respondents answer only the questions relevant to them. This reduces completion time and improves the user experience.

When designing the questionnaire, make sure that the branching is logical and easy to follow, and where possible, keep the number of different navigation paths to a minimum.

In online surveys, branching works automatically, so irrelevant questions are not shown to respondents. With paper questionnaires, by contrast, you need to give clear instructions, as respondents can easily overlook skip instructions.

PARTIMAP lets you create conditional questions.

This means that, depending on an answer, new questions are shown or remain hidden.

**Example:**

**Do you use a bicycle?**

○ Yes<br />
○ No

If the answer is **yes**, the questions about cycling infrastructure appear.

If **no**, they are skipped automatically.

Branching makes the questionnaire shorter and more personalized, which improves the completion rate.
